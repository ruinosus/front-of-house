# front-of-house → house-lights

**This repository moved.** front-of-house is one of the five skills of
[house-lights](https://github.com/ruinosus/house-lights) and is now called **service-blueprint**. Install it from there:

```
/plugin marketplace add ruinosus/house-lights
/plugin install house-lights@house-lights
```

If you installed `front-of-house` from this repository, remove it: `/plugin uninstall front-of-house@front-of-house`. Its files keep working
with the new skill. The gallery is now https://ruinosus.github.io/house-lights/service-blueprint/; the npm command is
`npx house-lights service-blueprint <file>`. This repository is archived and keeps its history and releases.
